# React Native — Práticas com Expo Snack

Repositório com atividades práticas desenvolvidas durante a graduação em **Ciência da Computação na Universidade de Fortaleza — Unifor**, utilizando **React Native** e **Expo Snack**.

O objetivo é registrar meu aprendizado em desenvolvimento mobile, explorando interfaces, navegação entre telas, gerenciamento de estado e persistência de dados.

## Práticas desenvolvidas

| Pasta | Conteúdo |
| --- | --- |
| [pratica-1](./pratica-1/) | Tela de apresentação pessoal com informações acadêmicas, ícones e links externos. |
| [pratica-2](./pratica-2/) | Interface de login e navegação para uma área do usuário, com passagem de parâmetros. |
| [pratica-3](./pratica-3/) | Opção de lembrar o e-mail utilizando armazenamento local com AsyncStorage. |
| [pratica4](./pratica4/) | Formulário de cadastro de produtos com integração ao Firebase Firestore. |
| [navegacaotelas](./navegacaotelas/) | Navegação entre uma tela de informações pessoais e um formulário de contato. |

## Tecnologias e conceitos

- JavaScript, React Native e Expo.
- Componentes funcionais e hooks `useState` e `useEffect`.
- Estilização de interfaces.
- Navegação com React Navigation.
- Armazenamento local com AsyncStorage.
- Integração com Firebase Firestore.

## Como explorar

Cada pasta corresponde a uma prática independente. Para testar no [Expo Snack](https://snack.expo.dev/), reproduza os arquivos da atividade e adicione as dependências indicadas em seu `package.json`.

A prática de cadastro de produtos também depende da configuração do Firebase Firestore.

As atividades têm finalidade acadêmica e representam diferentes etapas do meu aprendizado.
